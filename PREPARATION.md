# FullStory Connector — Preparation

**Category:** C40. Product Analytics & Behavioral  
**Status:** App Preparation Complete (Genuinely Vendor-Specific)  
**Standard:** APP_PREPARATION_STANDARD.md

## 1. Паспорт коннектора
- **Название:** FullStory Connector (`fullstory-connector`)
- **Официальный портал вендора:** https://fullstory.com
- **Базовый API:** `https://api.fullstory.com/v2`
- **Модель аутентификации:** API Key (Authorization: Basic <key>)
- **Назначение:** Интеграция платформы Imperal Cloud с FullStory для автоматизации предметной области: глубокий анализ сессий пользователей, воспроизведение багов интерфейса и обнаружение Rage Clicks.

## 2. Решаемая проблема
Когда **инженер технической поддержки** сталкивается с задачей **глубокий анализ сессий пользователей, воспроизведение багов интерфейса и обнаружение Rage Clicks**, возникает необходимость ручного мониторинга, дублирования статусов и переключения между окнами. Это приводит к потере времени, замедлению реакции на инциденты и ошибкам ручного ввода.

## 3. Роли и права доступа
- **инженер технической поддержки, QA-инженер, продакт-менеджер**
- Принцип наименьших привилегий (Least Privilege): токен запрашивает доступ только к разрешенным операциям чтения и подтвержденным действиям.

## 4. Ключевые сущности
сессии (/sessions), сегменты (/segments), кастомные события (/events), события фрустрации

## 5. Первичный рабочий сценарий
`поиск сессий с rage clicks по конкретной странице -> просмотр контекста ошибки -> передача баг-репорта`.

## 6. Границы коннектора
- Изолированное хранение секретов (BYOC).
- Никаких фиктивных методов сторонних предметных областей.
- Деструктивные операции требуют явного подтверждения пользователя.
